# O-Pilot

Orienteering copilot suite for Android (:mobile) and Wear OS (:wear).

## Features
- Auto-scan & Dewarp: ML Kit Document Scanner + PDF/Gallery import.
- CV Analysis (OpenCV): Automatic detection of magenta control points (ISOM) and meridian north alignment.
- Auto-Georeferencing: Multi-scale matching against OpenStreetMap (Overpass API) + two-finger manual fine-tuning over OSM/Satellite.
- Wear OS Companion: Standalone lodestone-style compass navigation on OnePlus Watch 4 with manual CP confirmation.
